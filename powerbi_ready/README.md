# Power BI Ready Datasets & Ingestion Guide

This folder contains clean, consolidated analytical datasets prepared from the Apache Spark batch processing pipeline (`output/`) and metadata (`data/cities.csv`).

---

## Directory Structure

```text
powerbi_ready/
├── Dim_City.csv           <- Dimension table with geographic coordinates and population (50 cities)
├── City_Monthly.csv       <- Longitudinal monthly facts (3,200 observations: 2020 to 2025)
├── City_Temperature.csv   <- Overall city temperature metrics (50 cities)
├── City_Rainfall.csv      <- Overall city precipitation and rainfall metrics (50 cities)
├── City_Wind.csv          <- Overall city wind speed metrics (50 cities)
├── City_Humidity.csv      <- Overall city humidity metrics (50 cities)
├── VALIDATION_REPORT.md   <- Row count, data type, uniqueness, and null verification audit
└── POWER_BI_GUIDE.md      <- Full Power BI architecture, DAX formulas, and visual dashboard guide
```

## Inspection of `City_Monthly.csv` Columns

Per the batch analytical transformations executed in `WeatherAnalytics.java`, the exact schema of `City_Monthly.csv` is:

| Expected Column | Present in `City_Monthly.csv`? | Actual Column Name | Source Table for Missing Metrics |
| :--- | :---: | :--- | :--- |
| **avg_temperature** | **YES** | `avg_temperature` | `City_Monthly.csv` |
| **max_temperature** | **NO** | *N/A in monthly table* | Found in `City_Temperature.csv` as `max_temperature` |
| **min_temperature** | **NO** | *N/A in monthly table* | Found in `City_Temperature.csv` as `min_temperature` |
| **avg_humidity** | **YES** | `avg_humidity` | `City_Monthly.csv` |
| **total_precipitation** | **YES** | `total_precipitation` | `City_Monthly.csv` |
| **avg_wind_speed** | **NO** | *N/A in monthly table* | Found in `City_Wind.csv` as `avg_wind_speed` |

> **Note**: No synthetic columns were added to `City_Monthly.csv`. The exact analytical values generated by Spark SQL were preserved with full decimal precision. For city-level max/min temperatures and wind speeds, relationships to `City_Temperature.csv` and `City_Wind.csv` are used.

## Data Ingestion into Power BI Desktop

1. Open **Power BI Desktop**.
2. Click **Get Data** > **Text/CSV**.
3. Navigate to `c:\Projects\Weather-analytics-Bda-\powerbi_ready\` and import each of the 6 CSV files:
   - `Dim_City.csv`
   - `City_Monthly.csv`
   - `City_Temperature.csv`
   - `City_Rainfall.csv`
   - `City_Wind.csv`
   - `City_Humidity.csv`
4. Click **Transform Data** to open the **Power Query Editor**.
5. Set appropriate Data Types:
   - `latitude`, `longitude`, temperatures, rainfall, humidity, and wind: **Decimal Number**.
   - `year`, `month`, `rank`, `population`: **Whole Number**.
   - `city_name`: **Text**.
6. Click **Close & Apply**.

For the complete data modeling, DAX measures, and visual design steps, see [POWER_BI_GUIDE.md](file:///c:/Projects/Weather-analytics-Bda-/powerbi_ready/POWER_BI_GUIDE.md).
