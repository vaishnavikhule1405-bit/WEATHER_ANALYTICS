# Power BI Comprehensive Implementation Guide
## Indian Cities Climate & Weather Analytics Dashboard

This guide provides end-to-end instructions for building a production-ready Power BI dashboard using analytical datasets generated by Apache Spark from 2.3+ million hourly weather observations across 50 Indian cities.

---

## 1. DATA MODEL (Star Schema)

The model is structured around a centralized geographic dimension (`Dim_City`), a temporal dimension (`Dim_Date`), and five fact tables:

```
                    ┌─────────────────────────┐
                    │        Dim_Date         │
                    │ (Calendar, Season, Qtr) │
                    └───────────┬─────────────┘
                                │ 1
                                │
                                │ *
┌───────────────────────┐ 1   * ┌─────────────────────────┐
│       Dim_City        ├───────┤      City_Monthly       │
│(Lat, Long, Population)│       │(Temp, Humidity, Precip) │
└───────────┬───────────┘       └─────────────────────────┘
            │
            ├─────────────── 1:1 (Single: Dim_City -> Fact) ───────────────┐
            │                     │                     │                  │
            ▼                     ▼                     ▼                  ▼
┌───────────────────────┐ ┌────────────────┐ ┌────────────────┐ ┌────────────────┐
│   City_Temperature    │ │ City_Rainfall  │ │   City_Wind    │ │ City_Humidity  │
│ (Avg, Max, Min Temp)  │ │ (Total, Avg,   │ │   (Avg, Max    │ │ (Avg, Max,     │
│                       │ │   Max Precip)  │ │    Wind Speed) │ │   Min Humidity)│
└───────────────────────┘ └────────────────┘ └────────────────┘ └────────────────┘
```

### Table Roles & Relationships

1. **`Dim_City` (Dimension Table)**:
   - Primary Key: `city_name` (Verified 100% unique across all 50 cities).
   - Attributes: `rank`, `latitude`, `longitude`, `population`.
2. **`Dim_Date` (Calendar Dimension Table)**:
   - Primary Key: `DateKey` (1st day of each month: `YYYY-MM-01`).
   - Attributes: `Year`, `Month Number`, `Month Name`, `Quarter`, `Season`.
3. **`City_Monthly` (Primary Granular Fact Table)**:
   - Foreign Keys: `city_name` (links to `Dim_City`), `DateKey` (links to `Dim_Date`).
   - Grain: One record per city per month (3,200 rows across 2020–2025).
4. **Summary Fact Tables (`City_Temperature`, `City_Rainfall`, `City_Wind`, `City_Humidity`)**:
   - Each contains exactly 50 rows corresponding to the 50 cities.
   - **Relationship Type**: `1 : 1` (or `1 : *` with single cross-filter direction: `Dim_City` filters the summary table). Uniqueness on `city_name` has been audited and confirmed.

## 2. DATE DIMENSION TABLE (DAX)

To support time-intelligence, seasonal grouping, and slicing, create a calculated table in Power BI named `Dim_Date`.

### Step 1: Create `Dim_Date` Table
In Power BI Desktop, click **Modeling** > **New Table** and paste:

```dax
-- IMPORTANT: Do NOT use CALENDAR() here. CALENDAR() creates DAILY rows,
-- which means DateKey (1st of month) will have duplicates and the 1:*
-- relationship to City_Monthly will fail.
--
-- RECOMMENDED: Import powerbi_ready/Dim_Date.csv instead (64 unique monthly rows).
--
-- If you prefer a DAX calculated table, use this MONTHLY formula:

Dim_Date = 
VAR AllMonths =
    GENERATE (
        SELECTCOLUMNS ( GENERATESERIES ( 2020, 2025, 1 ), "Year", [Value] ),
        SELECTCOLUMNS ( GENERATESERIES ( 1, 12, 1 ), "MonthNo", [Value] )
    )
VAR FilteredMonths =
    FILTER ( AllMonths, DATE ( [Year], [MonthNo], 1 ) <= DATE ( 2025, 4, 1 ) )
RETURN
    ADDCOLUMNS (
        FilteredMonths,
        "DateKey", DATE ( [Year], [MonthNo], 1 ),
        "MonthName", FORMAT ( DATE ( [Year], [MonthNo], 1 ), "MMMM" ),
        "MonthShort", FORMAT ( DATE ( [Year], [MonthNo], 1 ), "MMM" ),
        "Quarter", "Q" & FORMAT ( DATE ( [Year], [MonthNo], 1 ), "Q" ),
        "YearMonth", FORMAT ( DATE ( [Year], [MonthNo], 1 ), "YYYY-MM" ),
        "Season",
            SWITCH (
                TRUE (),
                [MonthNo] IN { 12, 1, 2 }, "Winter",
                [MonthNo] IN { 3, 4, 5 }, "Summer",
                [MonthNo] IN { 6, 7, 8, 9 }, "Monsoon",
                [MonthNo] IN { 10, 11 }, "Post-Monsoon"
            ),
        "SeasonOrder",
            SWITCH (
                TRUE (),
                [MonthNo] IN { 12, 1, 2 }, 1,
                [MonthNo] IN { 3, 4, 5 }, 2,
                [MonthNo] IN { 6, 7, 8, 9 }, 3,
                [MonthNo] IN { 10, 11 }, 4
            )
    )
```

### Step 2: Sort Columns in `Dim_Date`
- Select `MonthName` column > Click **Sort by column** > Select `MonthNo`.
- Select `MonthShort` column > Click **Sort by column** > Select `MonthNo`.
- Select `Season` column > Click **Sort by column** > Select `SeasonOrder`.

### Step 3: Add `DateKey` to `City_Monthly`
In `City_Monthly`, create a calculated column:

```dax
DateKey = DATE(City_Monthly[year], City_Monthly[month], 1)
```

Connect `Dim_Date[DateKey]` (1) $\rightarrow$ `City_Monthly[DateKey]` (*).

## 3. DAX MEASURES SPECIFICATION

Create a dedicated blank table named `_Measures` to house all core calculations.

### 1. Temperature Measures

```dax
Average Temperature = 
AVERAGE(City_Monthly[avg_temperature])
```

```dax
Maximum Temperature = 
MAX(City_Temperature[max_temperature])
```

```dax
Minimum Temperature = 
MIN(City_Temperature[min_temperature])
```

```dax
Temperature Range = 
[Maximum Temperature] - [Minimum Temperature]
```

---

### 2. Rainfall & Precipitation Measures

```dax
Total Rainfall = 
SUM(City_Monthly[total_precipitation])
```

```dax
Average Monthly Rainfall = 
AVERAGE(City_Monthly[total_precipitation])
```

---

### 3. Humidity & Wind Measures

```dax
Average Humidity = 
AVERAGE(City_Monthly[avg_humidity])
```

```dax
Average Wind Speed = 
AVERAGE(City_Wind[avg_wind_speed])
```

---

### 4. Text KPI Measures (Corrected Non-Scalar TOPN)

> **Important**: Power BI scalar measures cannot return a table directly from `TOPN()`. The standard enterprise practice is wrapping `TOPN` inside `CONCATENATEX` or `CALCULATE(SELECTEDVALUE())`.

```dax
Hottest City = 
CALCULATE(
    CONCATENATEX(
        TOPN(1, VALUES(City_Temperature[city_name]), City_Temperature[max_temperature], DESC),
        City_Temperature[city_name],
        ", "
    )
)
```

```dax
Wettest City = 
CALCULATE(
    CONCATENATEX(
        TOPN(1, VALUES(City_Rainfall[city_name]), City_Rainfall[total_precipitation], DESC),
        City_Rainfall[city_name],
        ", "
    )
)
```

```dax
Highest Humidity City = 
CALCULATE(
    CONCATENATEX(
        TOPN(1, VALUES(City_Humidity[city_name]), City_Humidity[avg_humidity], DESC),
        City_Humidity[city_name],
        ", "
    )
)
```

## 4. POWER BI REPORT PAGES DESIGN

---

### PAGE 1 — INDIA CLIMATE & WEATHER OVERVIEW

#### Visual Components & Layout
1. **Top KPI Cards Row**:
   - Card 1: `[Average Temperature]` (Format: `0.0 °C`)
   - Card 2: `[Maximum Temperature]` (Format: `0.0 °C`)
   - Card 3: `[Total Rainfall]` (Format: `#,##0 mm`)
   - Card 4: `[Average Humidity]` (Format: `0.0 %`)
   - Card 5: `[Hottest City]` (Text callout)
   - Card 6: `[Wettest City]` (Text callout)
2. **Interactive India Map (Left / Center Pane)**:
   - Visual Type: **Azure Map** or **Map (Bubble)**
   - Latitude: `Dim_City[latitude]`
   - Longitude: `Dim_City[longitude]`
   - Location: `Dim_City[city_name]`
   - Bubble Size: `[Total Rainfall]`
   - Bubble Color (Conditional Formatting):
     - Format Style: Gradient based on `[Average Temperature]`
     - Minimum: #2B83BA (Cool Blue, ~15°C)
     - Center: #FFFFBF (Pale Yellow, ~26°C)
     - Maximum: #D7191C (Vibrant Red, ~35°C+)
   - Tooltips: `city_name`, `Average Temperature`, `Total Rainfall`, `Average Humidity`, `population`.
3. **Top 10 Rankings (Right Pane)**:
   - **Visual A**: Clustered Bar Chart — *Top 10 Hottest Cities*
     - Y-Axis: `Dim_City[city_name]` (Filtered by Top 10 by `[Maximum Temperature]`)
     - X-Axis: `City_Temperature[max_temperature]`
     - Color: Amber/Flame Red (`#D95F02`)
   - **Visual B**: Clustered Bar Chart — *Top 10 Rainiest Cities*
     - Y-Axis: `Dim_City[city_name]` (Filtered by Top 10 by `[Total Rainfall]`)
     - X-Axis: `City_Rainfall[total_precipitation]`
     - Color: Deep Ocean Blue (`#1F78B4`)
4. **Header Slicers**:
   - `Dim_Date[Year]` (Tile / Horizontal buttons: 2020 – 2025)
   - `Dim_Date[Season]` (Dropdown: Summer, Monsoon, Post-Monsoon, Winter)
   - `Dim_City[city_name]` (Searchable dropdown with "Select All")

---

### PAGE 2 — CITY COMPARISON

Designed to compare two or more selected Indian cities across micro-climates.

#### Visual Components & Layout
1. **Selection Bar**:
   - Multi-select Slicer for `Dim_City[city_name]` (default selection: *Mumbai* vs *Delhi* vs *Bangalore*).
2. **Monthly Temperature Trajectory (Top Left)**:
   - Visual Type: **Line Chart**
   - X-Axis: `Dim_Date[MonthShort]` (sorted by `MonthNo`)
   - Y-Axis: `[Average Temperature]`
   - Legend: `Dim_City[city_name]`
   - Data labels: On hover / subtle markers.
3. **Extreme Temperature Range (Top Right)**:
   - Visual Type: **Clustered Column Chart**
   - X-Axis: `Dim_City[city_name]`
   - Y-Axis: `City_Temperature[max_temperature]` and `City_Temperature[min_temperature]`
   - Highlights the thermal variance between coastal (e.g. Mumbai, Chennai) vs continental/interior cities (e.g. Delhi, Jaipur).
4. **Rainfall vs. Humidity Dynamics (Bottom Left)**:
   - Visual Type: **Line and Clustered Column Chart**
   - X-Axis: `Dim_Date[MonthShort]`
   - Column Y-Axis: `[Total Rainfall]` (Bars)
   - Line Y-Axis: `[Average Humidity]` (Dashed Line)
   - Slices dynamic relationship between monsoon rainfall and atmospheric moisture.
5. **Wind Speed vs. Humidity Dispersion (Bottom Right)**:
   - Visual Type: **Scatter Chart**
   - X-Axis: `City_Wind[avg_wind_speed]`
   - Y-Axis: `City_Humidity[avg_humidity]`
   - Details: `Dim_City[city_name]`
   - Size: `Dim_City[population]`
   - Color: `Dim_City[city_name]`

---

### PAGE 3 — SEASONALITY & TRENDS

Highlights monsoon behavior, climate seasonality, and multi-year trends (2020–2025).

#### Visual Components & Layout
1. **Monsoon & Monthly Rainfall Timeline (Top Full Width)**:
   - Visual Type: **Area Chart**
   - X-Axis: `Dim_Date[MonthShort]` (or Continuous `Dim_Date[YearMonth]`)
   - Y-Axis: `[Total Rainfall]`
   - Highlights sharp monsoon precipitation surge during June, July, August, and September.
2. **City × Month Temperature Heatmap (Center Left)**:
   - Visual Type: **Matrix Visual**
   - Rows: `Dim_City[city_name]`
   - Columns: `Dim_Date[MonthShort]`
   - Values: `[Average Temperature]`
   - Conditional Formatting:
     - Background Color: Gradient on `Average Temperature` (Deep Blue [Lowest] $\rightarrow$ White [Median] $\rightarrow$ Crimson Red [Highest]).
3. **Seasonal Contribution Breakdown (Center Right)**:
   - Visual Type: **Donut Chart** or **Stacked Bar Chart**
   - Legend / Category: `Dim_Date[Season]`
   - Values: `[Total Rainfall]`
   - Demonstrates that Monsoon accounts for >75% of annual rainfall across Indian cities.
4. **Multi-Year Trend Analysis (Bottom Full Width)**:
   - Visual Type: **Line Chart**
   - X-Axis: `Dim_Date[Year]`
   - Y-Axis: `[Average Temperature]` and `[Total Rainfall]` (Secondary Axis)
   - Displays year-over-year annual climate variations across 2020, 2021, 2022, 2023, 2024, and 2025.

## 5. STEP-BY-STEP BUILD INSTRUCTIONS

### Step 1: Open Power BI Desktop
1. Launch Power BI Desktop.
2. Save the project immediately as `Indian_Weather_Analytics.pbix` in `c:\Projects\Weather-analytics-Bda-\`.

### Step 2: Import the 6 Clean Datasets
1. Click **Get Data** > **Text/CSV**.
2. Navigate to `c:\Projects\Weather-analytics-Bda-\powerbi_ready\`.
3. Select and import each file one by one:
   - `Dim_City.csv`
   - `City_Monthly.csv`
   - `City_Temperature.csv`
   - `City_Rainfall.csv`
   - `City_Wind.csv`
   - `City_Humidity.csv`
4. Click **Transform Data** to open the **Power Query Editor**.

### Step 3: Power Query Data-Type Configuration
In Power Query, verify each table:
1. **`Dim_City`**:
   - `rank`: Whole Number
   - `city_name`: Text
   - `latitude`: Decimal Number
   - `longitude`: Decimal Number
   - `population`: Whole Number
2. **`City_Monthly`**:
   - `city_name`: Text
   - `year`: Whole Number
   - `month`: Whole Number
   - `avg_temperature`: Decimal Number
   - `avg_humidity`: Decimal Number
   - `total_precipitation`: Decimal Number
3. **`City_Temperature`**:
   - `city_name`: Text
   - `avg_temperature`, `max_temperature`, `min_temperature`: Decimal Number
4. **`City_Rainfall`**:
   - `city_name`: Text
   - `total_precipitation`, `avg_precipitation`, `max_precipitation`: Decimal Number
5. **`City_Wind`**:
   - `city_name`: Text
   - `avg_wind_speed`, `max_wind_speed`: Decimal Number
6. **`City_Humidity`**:
   - `city_name`: Text
   - `avg_humidity`, `max_humidity`, `min_humidity`: Decimal Number
7. Click **Close & Apply** on the Home ribbon.

### Step 4: Geographic Classification in Data View
1. In the left navigation bar, switch to **Table View**.
2. Select table `Dim_City`:
   - Click column `latitude` > In **Column Tools** ribbon > Set **Data Category** = **Latitude**.
   - Click column `longitude` > Set **Data Category** = **Longitude**.
   - Click column `city_name` > Set **Data Category** = **City**.

### Step 5: Create the Date Table & Calculated Column
1. Go to **Modeling** ribbon > Click **New Table**.
2. Paste the DAX formula for `Dim_Date` from **Section 2**.
3. Select `MonthName` column > Set **Sort by Column** to `MonthNo`.
4. Switch to `City_Monthly` table > Click **New Column** > Enter:
   ```dax
   DateKey = DATE(City_Monthly[year], City_Monthly[month], 1)
   ```

### Step 6: Configure Model Relationships
1. Switch to **Model View** (left navigation bar).
2. Create the following relationships by dragging and dropping:
   - `Dim_City[city_name]` (1) $\rightarrow$ `City_Monthly[city_name]` (*)
     - Cardinality: One to Many (1:*)
     - Cross filter direction: Single
   - `Dim_Date[DateKey]` (1) $\rightarrow$ `City_Monthly[DateKey]` (*)
     - Cardinality: One to Many (1:*)
     - Cross filter direction: Single
   - `Dim_City[city_name]` (1) $\rightarrow$ `City_Temperature[city_name]` (1)
     - Cardinality: 1 to 1 (or 1 to Many with Single cross-filter)
   - `Dim_City[city_name]` (1) $\rightarrow$ `City_Rainfall[city_name]` (1)
     - Cardinality: 1 to 1 (or 1 to Many with Single cross-filter)
   - `Dim_City[city_name]` (1) $\rightarrow$ `City_Wind[city_name]` (1)
     - Cardinality: 1 to 1 (or 1 to Many with Single cross-filter)
   - `Dim_City[city_name]` (1) $\rightarrow$ `City_Humidity[city_name]` (1)
     - Cardinality: 1 to 1 (or 1 to Many with Single cross-filter)

### Step 7: Create DAX Measures Table
1. In Home ribbon > Click **Enter Data**.
2. Set Table Name to `_Measures` and click **Load**.
3. In `_Measures`, create all measures from **Section 3** using **New Measure**.
4. Right-click and delete the default dummy `Column1`.

### Step 8: Build Page 1 (India Overview)
1. Rename Page 1 to `India Climate Overview`.
2. Add a Title Text Box: **"Indian Cities Weather & Climate Analytics (Apache Spark Pipeline)"**.
3. Add a **Card Visual** for each of: `[Average Temperature]`, `[Maximum Temperature]`, `[Total Rainfall]`, `[Average Humidity]`.
4. Add a **Map Visual**:
   - Location: `Dim_City[city_name]`
   - Latitude: `Dim_City[latitude]`
   - Longitude: `Dim_City[longitude]`
   - Bubble size: `[Total Rainfall]`
   - In Visual Formatting > Bubbles > Colors > Click `fx` > Set Gradient from Blue (`#2B83BA`) to Red (`#D7191C`) based on `[Average Temperature]`.
5. Add **Clustered Bar Chart** (Top Hottest):
   - Y-Axis: `Dim_City[city_name]`.
   - X-Axis: `City_Temperature[max_temperature]`.
   - In Filters Pane > `city_name` > Filter Type: **Top N** > Show top: **10** by `[Maximum Temperature]`.
6. Add **Clustered Bar Chart** (Top Rainiest):
   - Y-Axis: `Dim_City[city_name]`.
   - X-Axis: `City_Rainfall[total_precipitation]`.
   - In Filters Pane > `city_name` > Filter Type: **Top N** > Show top: **10** by `[Total Rainfall]`.
7. Add Slicers:
   - `Dim_Date[Year]` (Tile buttons).
   - `Dim_Date[Season]` (Dropdown).
   - `Dim_City[city_name]` (Dropdown).

### Step 9: Build Page 2 (City Comparison)
1. Click **+** to add a page > Rename to `City Comparison`.
2. Add Slicer: `Dim_City[city_name]` (Multi-select enabled).
3. Add **Line Chart**:
   - X-Axis: `Dim_Date[MonthShort]`
   - Y-Axis: `[Average Temperature]`
   - Legend: `Dim_City[city_name]`
4. Add **Clustered Column Chart**:
   - X-Axis: `Dim_City[city_name]`
   - Y-Axis: `City_Temperature[max_temperature]`, `City_Temperature[min_temperature]`
5. Add **Line and Clustered Column Chart**:
   - X-Axis: `Dim_Date[MonthShort]`
   - Column Y-Axis: `[Total Rainfall]`
   - Line Y-Axis: `[Average Humidity]`
6. Add **Scatter Chart**:
   - X-Axis: `City_Wind[avg_wind_speed]`
   - Y-Axis: `City_Humidity[avg_humidity]`
   - Values / Details: `Dim_City[city_name]`
   - Size: `Dim_City[population]`

### Step 10: Build Page 3 (Seasonality & Trends)
1. Click **+** to add a page > Rename to `Seasonality & Trends`.
2. Add **Area Chart**:
   - X-Axis: `Dim_Date[MonthShort]`
   - Y-Axis: `[Total Rainfall]`
3. Add **Matrix Visual** (Temperature Heatmap):
   - Rows: `Dim_City[city_name]`
   - Columns: `Dim_Date[MonthShort]`
   - Values: `[Average Temperature]`
   - In Visual Formatting > Cell elements > Turn on **Background color** > Set 3-color gradient (Blue $\rightarrow$ White $\rightarrow$ Red).
4. Add **Donut Chart**:
   - Legend: `Dim_Date[Season]`
   - Values: `[Total Rainfall]`
5. Add **Line Chart** (Multi-year Trend):
   - X-Axis: `Dim_Date[Year]`
   - Y-Axis: `[Average Temperature]`

### Step 11: Apply Professional Theme
1. In **View** ribbon > Themes gallery.
2. Select **Executive**, **Innovate**, or **Storm**.
3. Enable **Gridlines** and **Snap to Grid** for alignment.
4. Set visual backgrounds to subtle card containers with rounded corners (Corner radius: 6px) and light dropshadows.

### Step 12: Validate Filters & Cross-Highlighting
1. Click on a city on the Map on Page 1: verify that KPI cards and Top 10 rankings filter appropriately.
2. Change the Year slicer to `2023`: verify that monthly figures, rainfall, and temperature values update dynamically.
3. Select `Monsoon` in the Season slicer: verify that rainfall spikes and temperature moderates across visual cards.
4. Save the `.pbix` file.
